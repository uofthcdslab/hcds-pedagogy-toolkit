# Module 4: Problem Framing and Scoping

This module introduces students to human-centered problem framing and scoping in data science. Students use the COMPAS recidivism dataset to examine how research questions, variables, outcomes, and fairness metrics shape algorithmic auditing. The module then transfers these ideas to Gender Shades and FairFace to consider representation, consent, responsible reuse, reproducibility, accessibility, and openness.

## Learning Outcomes

By the end of this module, students will be able to:

- Reframe optimization prompts with human goals
- Define “success” beyond evaluation metrics
- Anticipate human-centered trade-offs
- Examine human-centered problem framing, ethical scoping, reproduction, and communication across real-world case studies
