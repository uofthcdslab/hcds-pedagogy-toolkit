# Module 2: Foundations + Critical Lens on the Data Science Lifecycle

This module introduces students to the data science lifecycle through a human-centered lens. It helps students identify where human decisions, abstractions, and risks enter data science workflows.

## Learning outcomes

By the end of this module, students should be able to:

- Describe the data science lifecycle and locate human touchpoints
- Explain abstraction traps
- Discuss harm beyond accuracy

## Suggested use

This module can be used as a standalone session or as part of a broader course sequence on Human-Centered Data Science. The materials are designed to support discussion of the data science lifecycle, human touchpoints, abstraction traps, and harms that may not be visible through accuracy metrics alone.
