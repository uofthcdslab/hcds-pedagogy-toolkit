# Module 3: Data Practices + Responsible Modeling

This module introduces students to responsible data practices and modeling through a human-centered lens. It helps students think critically about data handling, representation, subgroup analysis, and documentation in machine learning workflows.

## Learning outcomes

By the end of this module, students should be able to:

- Collect, clean, and document data responsibly, including imputation
- Discuss data representation, including underrepresentation
- Interpret models with subgroup analysis
- Introduce model cards and datasheets

## Suggested use

This module can be used as a standalone session or as part of a broader course sequence on Human-Centered Data Science. The materials are designed to support discussion of responsible data collection and cleaning, data representation, subgroup analysis, model documentation, and the risks that can emerge in machine learning workflows.
